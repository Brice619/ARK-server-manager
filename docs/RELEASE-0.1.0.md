# ARK Server Manager 0.1.0

First public release of the free desktop manager for local ASA and ASE servers and clusters.

Download `ARK-server-manager-setup-win-x64.exe` for Windows, or extract `ARK-server-manager-setup-linux-x64.tar.gz` on Linux and run its installer. The other ZIP files are for automatic app updates.

- Guided server/cluster creation, optional setup downloads and confirmed existing-server registration, copy or move.
- Start, stop, restart, crash recovery, map settings, passwords, welcome messages and shared cluster defaults.
- Mod IDs, optional metadata/artwork, mod ordering, presets and configuration-file editing.
- Runtime-based hourly backups, separate shared cluster state, archive verification and restoration.
- Background management, scheduled restarts, networking tools, notifications and launch-time app updates.
- Spacious scrolling cards and separate settings categories, following the approved dark-and-amber design.

The Windows/Linux release build passes 802 automated checks. The installed Windows application has opened and connected to its background manager, and the creation guide has been exercised through location/port review. Existing development evidence also covers real Windows ASA/ASE startup/save/stop, ASE world restoration and selected mod installation.

Linux runtime testing is intentionally deferred. The installers are unsigned. Full live player/mod/platform coverage, privileged live snapshot capture and further unusual interruption scenarios are not claimed verified. See [Deferred work](https://github.com/Brice619/ARK-server-manager/blob/main/docs/DEFERRED-WORK.md) for the complete list and [Getting started](https://github.com/Brice619/ARK-server-manager/blob/main/docs/GETTING-STARTED.md) for instructions.

Checksums and a release manifest accompany the installers. Bundled dependency license notices are included in the payloads.
